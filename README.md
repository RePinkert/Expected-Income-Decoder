# 黄金投资分析工具集

基于 Python + Jupyter Notebook 的黄金投资分析工具，包含内外盘价差分析和定投策略收益回测两大核心功能。

## 项目简介

本工具集提供黄金投资的量化分析能力：

- **价差分析**：基于国内 AU9999 金条和伦敦金的当前价格，分析两者之间的价差关系，判断套利机会
- **定投回测**：模拟不同定投周期和策略的收益表现，包括普通定投和基于均线的智能定投

## 功能模块

### 1. 黄金内外盘价差分析 (`gold_price_converter.ipynb`)

实时获取上海黄金交易所 AU9999 和伦敦金价格，计算内外盘价差。

**核心公式：**

```
换算AU9999（元/克）= 伦敦金（美元/盎司）× 汇率 ÷ 31.1035
内外盘价差 = 换算AU9999 - 实际AU9999
价差比 = 内外盘价差 / 实际AU9999 × 100%
```

**特点：**
- 自动从 akshare 获取实时价格数据
- 支持批量计算多个价格场景
- 自动回退到默认值（当 API 获取失败时）

### 2. 黄金定投策略收益分析 (`gold_dip_return_analysis.ipynb`)

基于历史数据的定投策略回测与可视化分析。

**功能特性：**

| 功能 | 说明 |
|------|------|
| 普通定投模拟 | 按周定投，支持自定义定投金额和星期几 |
| 滚动窗口分析 | 计算所有可能的定投起始组合的收益率 |
| 可视化分析 | 收益率分布直方图、时间序列、统计汇总 |
| 智能定投策略 | 基于 500 日均线（约 2 年）的智能定投 |
| 策略对比 | 普通定投 vs 智能定投的详细对比分析 |

**智能定投分档规则：**

| 高于均线 | 投资倍数 | 低于均线 | 投资倍数 |
|:--------:|:--------:|:--------:|:--------:|
| 0-15%    | 0.9x     | 0-15%    | 1.1x     |
| 15-50%   | 0.8x     | 15-30%   | 1.3x     |
| 50-100%  | 0.7x     | 30-40%   | 1.6x     |
| 100%+    | 0.6x     | 40%+     | 2.1x     |
